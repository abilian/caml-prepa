Write OCaml on the left, as taught in French classes préparatoires. On the right, the compiler shows what the programme prints, the types it worked out, where each name is visible, the Python it translates to, and the run one step at a time. Everything happens in your browser.

Your programme, written back out from the tree the compiler built. A bracket you did not write shows how it grouped your code.
