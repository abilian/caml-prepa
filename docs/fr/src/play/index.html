Ce qu'affiche le programme. Il est exécuté deux fois, par l'interpréteur et sous forme de Python compilé, et la ligne en haut à droite dit si les deux ont affiché la même chose.

Le type de chaque définition de premier niveau, trouvé par le compilateur. 'a veut dire « n'importe quel type ».

Où chaque nom peut servir. Chaque ligne est une partie du programme qui ouvre une portée, avec les noms qu'elle y introduit. Cliquez sur une ligne pour la retrouver dans le source.

Le même programme, traduit en Python par le compilateur.

Votre programme, réécrit à partir de l'arbre que le compilateur a construit. Une parenthèse que vous n'aviez pas écrite montre comment il a groupé votre code.

L'exécution, une évaluation à la fois. Le jaune marque l'expression sur le point d'être évaluée, le vert celle qui vient de produire sa valeur.
